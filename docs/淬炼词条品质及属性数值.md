# 淬炼词条品质及属性数值

> 数据文件：`src/data/refineAffixStats.ts`（暂未接入前端）

## 品质（由低到高）

平凡 → 良质 → 上乘 → 精妙 → 卓越 → 超凡 → 绝伦 → 臻极 → 造化 → 天工

## 简述品质（不填属性表）

| 品质 | 说明 |
|------|------|
| 平凡 | 最低档，前期过渡用 |
| 良质 | 次低档，仍属前期过渡 |
| 上乘 | 精妙前最后一档过渡品质 |

## 淬炼等级与可出品质

从 **淬炼 5 级** 起统计：

| 淬炼等级 | 可淬炼品质范围 |
|----------|----------------|
| 5 ~ 6 | 精妙、卓越、超凡、绝伦 |
| 7 ~ 8 | 卓越、超凡、绝伦、臻极 |
| 9 | 卓越、超凡、绝伦、臻极、造化 |
| 10 | 超凡、绝伦、臻极、造化 |
| 11 | 超凡、绝伦、臻极、造化、天工 |
| 12 | 绝伦、臻极、造化、天工 |

## 属性数值表

单位：%。**同品质下，PVP增伤与法术暴伤数值范围相同。**

| 品质 | PVP增伤 | 法术暴伤 |
|------|---------|----------|
| 精妙 | 3.0% ~ 4.5% | 3.0% ~ 4.5% |
| 卓越 | 4.5% ~ 5.4% | 4.5% ~ 5.4% |
| 超凡 | 5.4% ~ 6.3% | 5.4% ~ 6.3% |
| 绝伦 | 6.3% ~ 7.2% | 6.3% ~ 7.2% |
| 臻极 | 待填 | 待填 |
| 造化 | 待填 | 待填 |
| 天工 | 待填 | 待填 |

## 备注

- 相邻品质区间首尾相接（如精妙上限 = 卓越下限 = 4.5%）
- 臻极 / 造化 / 天工 的区间待补齐后写入数据文件即可
